В директории `lesson_10` создать директорию `enabled`, в ней создать symlink на `available/app.conf`
```
sysadmin@ubuntu:~/home_works/lesson_10$ tree
.
├── available
│   ├── app.conf
│   ├── app.log
│   └── readme.md
└── enabled
    └── app.conf -> ../available/app.conf

3 directories, 4 files
```
В директории `lesson_10` создать директории `logs` и `debug`; переместить файл `available/app.log` в директорию `logs`, а в `debug` сделать hardlink на `logs/app.log`

```
sysadmin@ubuntu:~/home_works/lesson_10$ tree
.
├── available
│   ├── app.conf
│   └── readme.md
├── debug
│   └── app.log
├── enabled
│   └── app.conf -> ../available/app.conf
└── logs
    └── app.log

5 directories, 5 files
sysadmin@ubuntu:~/home_works/lesson_10$ ls -li logs/app.log debug/app.log
525734 -rw-rw-r-- 2 sysadmin sysadmin 0 Aug 17 08:37 debug/app.log
525734 -rw-rw-r-- 2 sysadmin sysadmin 0 Aug 17 08:37 logs/app.log
```

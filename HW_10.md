Cозданы директории с файлами
```
artsiom@ubundu26:~/home_works$ tree
.
└── lesson_10
    └── avaible
        ├── app.conf
        ├── app.log
        └── readme.md

3 directories, 3 files
```

В директории `lesson_10` создать директорию `enabled`, в ней создать symlink на `available/app.conf`
```
artsiom@ubundu26:~/home_works/lesson_10$ ln -s ../available/app.conf enabled/app.conf
artsiom@ubundu26:~/home_works/lesson_10$ tree
.
├── avaible
│   ├── app.conf
│   ├── app.log
│   └── readme.md
└── enabled
    └── app.conf -> ../available/app.conf
```

В директории `lesson_10` создать директории `logs` и `debug`; переместить файл `available/app.log` в директорию `logs`
```
artsiom@ubundu26:~/home_works/lesson_10$ mkdir logs debug
artsiom@ubundu26:~/home_works/lesson_10$ mv avaible/app.log logs
artsiom@ubundu26:~/home_works/lesson_10$ tree
.
├── avaible
│   ├── app.conf
│   └── readme.md
├── debug
├── enabled
│   └── app.conf -> ../available/app.conf
└── logs
    └── app.log
```
